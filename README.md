# Lok Sabha Elections 2024 – Data Analytics Project

## Project Overview
An end-to-end data analytics project exploring the results of the 2024 Indian General Elections using MS-Excel, MySQL and Microsoft Power BI.

The project focuses on analyzing election results, constituency distribution, political party performance, candidate statistics, voting patterns, and state-wise election outcomes.

## Tools & Technologies
- MySQL
- Microsoft Power BI
- SQL
- Excel
- Data Cleaning and Data Transformation
- Data Visualization

## Project Objectives
- Analyze election results across Indian constituencies.
- Identify top-performing political parties.
- Evaluate candidate-level performance.
- Analyze state-wise election outcomes.
- Explore winning margins and voting patterns.
- Present insights through interactive dashboards.

## Dashboard Pages

## Project Workflow

## Key Insights
--> ND Alliance has secured majority with 293 seats with 15 parties in alliance.

--> INDI Alliance has secured 234 seats with 20 parties in alliance.  

--> ND Alliance has failed to secure single seat in 4 states: Manipur, Punjab, Tamil Nadu, Uttarakhand.

--> INDI Alliance has failed to secure single seat in 6 states: Andhra Pradesh, Arunachal Pradesh, Himachal Pradesh, Madhya Pradesh, Delhi, Tripura. 

--> Independent candidates have secured 16 seats.

--> Telugu Desam Party has highest average candidate voting.

--> Bharatiya Janata Party has highest percent of votes & seats followed by Indian National Congress and Samajwadi Party.

--> Dravida Munnetra Kazhagam is only party to secure 100% winning conversion despite having candidates in double digit ( 22 Candidates All Won ).

---> States having multiple constituencies like  Arunachal Pradesh, Himachal Pradesh, Delhi, Tripura, Uttarakhand were won single handedly by BJP.

--> State like Manipur were won single handedly by Indian National Congress.

--> Mukesh Kumar Dalal (BJP) won election from Surat constituency without opposition. 

--> Shankar Lalwani (BJP) won election with highest margin (1175092 votes).

--> Ravindra Dattaram Waikar (Shiv Sena) won election with lowest margin (48 votes).

--> Rahul Gandhi was only candidate to be able to secure wins in 2 constituencies.

--> 6372220 votes were casted to NOTA which make about 1% of total votes casted in 2024 elections.

--> Only 7 candidates were able to secure wins Independently i.e without any party.

--> West Bengal has highest average voting per seat showing awareness of voting.

--> Bharatiya Janata Party has most states with majority seats in 20 States. 

--> Samajwadi Party has highest number of seats a party has won in any particular state
